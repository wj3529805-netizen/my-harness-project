# 本机导入界面

这是给日常拷入用的本机网页。它调用现有的 `plan_import`、`approve` 和 `execute`，自己不拷贝文件。本次只做 ingest：不调用模型，不连接 Lightroom，也不读取桥 token。

纯 NEF、纯 JPG 和混合批次都会进入计划。缺了另一种格式不会把还在的照片丢掉。来源只读。目标里已有且内容不同的文件会显示冲突，不会被覆盖。

## 依赖与启动

需要仓库里的 Python 3.13 虚拟环境（`.venv`），没有额外的网页依赖，也不需要 API key。

在 Mac 上双击 `scripts/mac/CETACEA导入.command`。终端会打开 `http://127.0.0.1:8765`（若被占用则顺延到后 9 个端口）。界面只监听 `127.0.0.1`。

也可以在仓库根目录执行：

```sh
.venv/bin/python -m cetacea.import_desk
```

不想自动打开浏览器时加上 `--no-browser`。

## 退出

在网页点击「退出导入界面」，或在启动它的终端按 Ctrl+C，或直接关掉那个终端窗口。

## 使用

1. 在访达里自己建好三个空目录：状态、照片库、预览。界面不预填路径。
2. 粘贴这三个绝对路径并新建工作台，或打开已有工作台。打开时只列出已有订单、摄影师和来源，不扫描照片。
3. 登记或选择来源、订单、摄影师。来源必须是已存在的真实目录。
4. 点击「查看计划」。核对来源、目标、数量、格式、大小，以及「仅拷入」。
5. 勾选包含目标路径和计划摘要的确认，再点一次「确认并开始拷入」。计划变化后旧摘要不能启动。重复点击不会再启动一次。
6. 看进度、每个文件的校验结果，以及成功或失败。完成后可以打开成品目录。

目标位置就是这个工作台的照片库。要写到新的地方，请新建工作台并选择新的库目录，不要沿用生产 NAS 或旧资料，除非计划里你再次确认了那条路径。

## Mac 上还要做的一次真机验收

云端 Linux 测试不能代替这次验收。在 Mac 的当前检出上：

1. 确认代码是本 PR 的提交，不要合并到 `phase1`。
2. 双击启动器。用三个新建的空目录做工作台，不要指向整张卡、客户目录或生产 NAS。
3. 来源只选已经准备好的小目录。查看计划时核对数量和「仅拷入」，确认目标路径就是新库。
4. 批准一次。结果应全部为已读回校验；再点一次按钮不应第二次导入。
5. 打开成品目录，抽查文件，并确认来源目录的内容和修改时间没变。
