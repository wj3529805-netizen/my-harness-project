# 工具结果如何到达 DeepSeek

Harness 是 MCP 客户端，也是 LLM agent 循环。工具执行后，Harness 将每个工具结果追加到对话中；每次请求时把整个对话 POST 给 DeepSeek API，因为模型只能基于收到的文本推理。因此工具返回的订单或摄影师 ID、批次标签、文件名、文件大小、SHA-256、目标相对路径、`photo_list_sources` 返回的来源绝对路径以及 Lightroom 状态文字都会离开本机，到达 DeepSeek 的服务器。工具只接受注册 ID，并不意味着其返回值只含 ID。

当前工具不返回照片像素或文件字节，因此模型不会通过这些工具收到文件内容。文件名、路径和其他元数据仍可能包含敏感信息。

可考虑将工具返回值限制为 ID/标签、使用假名化订单 ID，以及在未来的工具层重命名或隐藏文件名；来源列表也可考虑只返回 ID/标签。作出数据处理和合同决策前避免使用真实客户数据，并审阅用户自己适用的 DeepSeek 数据保留条款。
