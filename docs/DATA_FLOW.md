# 工具结果如何到达 DeepSeek

Harness 是 MCP 客户端，也是 LLM agent 循环。工具执行后，Harness 将每个工具结果追加到对话中；每次请求时把整个对话 POST 给 DeepSeek API，因为模型只能基于收到的文本推理。因此工具返回的订单或摄影师 ID、批次标签、文件名、文件大小、SHA-256、图库相对路径、任务/阶段状态、`photo_list_sources` 返回的来源绝对路径以及 Lightroom 状态文字都可能离开本机，到达 DeepSeek 的服务器。工具只接受注册 ID，并不意味着其返回值只含 ID。

当前工具不返回照片像素或文件字节，因此模型不会通过这些工具收到文件内容。文件名、路径和其他元数据仍可能包含敏感信息。

## 用户决定（2026-11-02）

用户在聊天中表示“没问题 可以交给deepseek”，接受将包含真实客户数据的 CETACEA 工具结果发送给 DeepSeek。决定覆盖订单 ID、摄影师 ID、批次标签、文件名、文件大小、SHA-256 哈希、图库相对路径、任务/阶段状态和 Lightroom 状态文字。

硬边界仍为不发送照片像素或文件内容；当前没有工具返回文件字节。此决定不覆盖未来返回文件内容或缩略图的工具，也不改变 DeepSeek 自身的数据保留条款；用户仍负责审阅适用条款。

**开放风险，待用户决定：**`photo_list_sources` 会向模型返回来源的绝对文件系统路径，可能暴露用户名、目录结构或卷名；该路径不在上述决定范围内。建议后续改为只返回来源 ID/标签，等待用户决定。
